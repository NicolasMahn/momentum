# Glossary

The words Momentum uses for its own ideas, in every language it speaks. A screen, a notification and Mo say the same thing with the same word. Ordinary words are translated as they naturally are; this list is only for words that need a decision.

English is British English: colour, practise, holiday. It is the default language of the store listing (en-GB). German speaks with *du*, short and warm. Mo is playful and never scolds. Names a person typed (a checklist, an item, an activity) are shown as typed.

## Game words

Mo's game has its own objects. They keep one name in every language, like a brand: translating them literally ("Eisblock") turns a thing you collect into a description.
